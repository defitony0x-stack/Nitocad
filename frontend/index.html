How it works

One description, one real part.

Submit a plain description, get back a validated, sized part with the exact parameters used, no CAD software required on your end.

01

Describe

Plain English in: dimensions, hole counts, fillets, material. DeepSeek parses it into structured parameters, with a regex-based fallback if no key is configured.

02

Generate & validate

CadQuery drives OpenCASCADE to compute exact B-rep geometry. A validator catches impossible geometry (a fillet too large for the material, a hole bigger than the wall) and auto-corrects it before export.

03

Export

Get back a real .STEP file for manufacturing or import into any CAD tool, plus an .STL for a quick 3D preview.

Templates

23 parametric part types

Brackets (L, T, channel), shafts, gears, pulleys, sprockets, bearings, structural beams, tube, pipe fittings, flanges, hinges, cams, hex standoffs, and freeform revolve/sweep/loft shapes.

Parsing

DeepSeek + regex fallback

Real LLM parameter extraction when a key is configured, automatic regex-based fallback when it isn't. Never fails to at least attempt a part.

Validation

Geometric sanity checks

Catches and auto-corrects impossible geometry before export, a fillet too large for its material, a hole bigger than the wall it's cut in.

Export

STEP + STL export

A real, manufacturable STEP file plus an STL for a quick 3D preview, both computed by OpenCASCADE's B-rep kernel.

Access

Single-call API

One request, one part. No polling required for a standard template part, the whole pipeline runs synchronously.
